PlaqueGCode – Politique de confidentialité

Dernière mise à jour : 24 septembre 2026

Données collectées

PlaqueGCode ne collecte, ne stocke et ne transmet aucune donnée personnelle. L'application fonctionne entièrement hors ligne sur votre ordinateur : elle n'utilise aucun compte, aucune télémétrie, aucune statistique d'usage, aucune publicité et aucun service tiers.

Fichiers

Les textes saisis et les réglages d'usinage servent uniquement à générer le fichier G-code (.iso) que vous choisissez d'enregistrer sur votre ordinateur. Ce fichier reste sur votre machine ; l'application ne l'envoie nulle part.

Connexion réseau

L'application n'établit aucune connexion réseau.

Autorisation « runFullTrust »

PlaqueGCode est un programme Windows classique. Le Microsoft Store impose de déclarer cette autorisation pour ce type de programme ; elle n'est utilisée que pour enregistrer le fichier G-code à l'emplacement que vous indiquez.

Sécurité d'utilisation

Le G-code généré commande une machine-outil. Vérifiez toujours le fichier et les réglages (vitesses, profondeurs, position de l'origine) avant de lancer l'usinage. L'application est fournie sans garantie.

Contact

Pour toute question : plaquegcode@gmail.com

PlaqueGCode – Privacy Policy

Last updated: September 24, 2026

Data collected

PlaqueGCode does not collect, store or transmit any personal data. The application runs entirely offline on your computer: no account, no telemetry, no usage statistics, no advertising and no third-party service.

Files

The text you type and the machining settings are used only to generate the G-code (.iso) file that you choose to save on your computer. The file stays on your machine; the application never sends it anywhere.

Network

The application makes no network connection.

Safety

The generated G-code drives a machine tool. Always check the file and the settings (speeds, depths, origin position) before starting a job. The application is provided without warranty.
